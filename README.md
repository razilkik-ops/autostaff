# SGCB Russia

Интернет-магазин профессиональных товаров для детейлинга SGCB с каталогом, страницами товаров, корзиной, блогом, новостями и заявками в Telegram.

Страницы статей поддерживают товарные вставки, Schema.org-разметку, SEO-заголовки и описания, изображения, видеоблоки, комментарии, лайки, отправку ссылки, подписку и похожие материалы.

## Telegram-заказы

Добавьте в серверное окружение две секретные переменные:

- `TELEGRAM_BOT_TOKEN` — токен бота от BotFather.
- `TELEGRAM_CHAT_ID` — ID чата, группы или канала, куда приходят заявки.

Секреты не нужно добавлять в клиентский код или публиковать в Git. При отсутствии переменных форма покажет понятную ошибку.

## Запуск

```bash
npm install
npm run dev
```

Проверка сборки:

```bash
npm run build
npm run test:sites
```

## GitHub Pages

Публичная версия собирается командой `npm run build:pages` с базовым путём `/autostaff/`. Публикация запускается автоматически из workflow `.github/workflows/pages.yml` после каждого push в `main`.

GitHub Pages обслуживает только статические файлы. Для приёма заказов в Telegram переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` должны находиться в отдельном серверном окружении, а URL этого API — подключаться к клиентской сборке; секретный токен нельзя помещать в GitHub Pages.
